Semáforo mensual

cobranza y rentabilidad, todos los meses del año a la vez
iFacturación: compara lo facturado ese mes (neto de notas de crédito) contra la meta mensual configurada en Ajustes — verde si llegó al 100% o más, amarillo 70-99%, rojo bajo 70%. Gris = ese mes no tiene meta configurada. Rentabilidad: verde/amarillo/rojo según el margen (facturado menos costos) de las facturas de ese mes que ya tienen costo cargado. Gris = todavía no hay costos cargados para ese mes.

Parámetros de cobranza

Por defecto 30 días: vencimiento = fecha de emisión + este plazo. Se aplica al simular, importar o agregar manualmente una factura, salvo que el cliente tenga un plazo propio abajo.
Si un cliente tiene un plazo propio, se usa en vez del plazo general de arriba para sus próximas facturas (nuevas, importadas o manuales).
Define cuándo una factura pasa a amarillo en el semáforo.
Se usa para cualquier mes que no tenga su propia meta abajo. Déjalo en 0 para ocultar el semáforo mensual cuando no hay meta específica.
Deja un mes en blanco para que use la meta por defecto de arriba. Útil para temporadas bajas o altas.
Semáforo grande aparte, siempre del año en curso completo, sin importar los filtros. Déjalo en 0 para ocultarlo.

Enviar correos desde la plataforma (EmailJS)

Con esto, el botón "Enviar cobranza" de Clientes manda el correo directo desde el dashboard, sin abrir tu Gmail, y queda un historial de cuántos correos se han enviado a cada cliente. Necesitas una cuenta gratuita en emailjs.com conectada a tu Gmail (una vez), y pegar aquí sus 3 datos. Si dejas estos campos vacíos, el botón sigue funcionando como hasta ahora (abre tu correo).

Plantillas de correo (predeterminadas)

Deja acá el texto que quieres que traiga cada correo por defecto. Nunca se manda solo — siempre hace falta apretar "Enviar cobranza" o "Enviar factura" a mano; esto solo predefine el asunto y el cuerpo. Puedes usar estos campos entre llaves, que se reemplazan al enviar:
Cobranza: {cliente} {saldo} {detalle} {empresa}
Factura: {cliente} {folio} {emision} {vencimiento} {monto} {concepto} {empresa}

Importar Libro de Ventas (RCV)

Sube aquí el archivo CSV del Libro de Ventas (RCV) que descargas del SII. El dashboard va a leer las facturas nuevas, calcular su vencimiento (emisión + plazo de cobranza configurado arriba), registrar las notas de crédito como documentos propios (se restan de lo facturado en el mes en que se emitió la NC, no en el mes de la factura original — igual que en el Libro de Ventas), marcar como "Anulada (NC)" las facturas que quedan totalmente cubiertas y rebajar el saldo de las que solo quedan cubiertas en parte, y omitir las que ya existían (por folio) para no duplicar.

Publicar cambios en GitHub

Lo que importas o marcas como pagado aquí solo se guarda en este navegador. Configura esto una sola vez y desde entonces el botón "Guardar y publicar" sube el facturas.json actualizado directo a tu repositorio de GitHub — sin descargar ni pegar nada a mano. Las demás personas verán los cambios apenas recarguen el link (1-2 minutos).

Se guarda solo en este navegador y solo se usa para hablar con GitHub. Crea uno en GitHub → foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → "Generate new token", dale acceso solo a este repositorio, y en permisos ("Repository permissions") elige Contents: Read and write. Copia el token generado (empieza con "github_pat_" o "ghp_") y pégalo aquí.
