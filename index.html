Parámetros de cobranza

Por defecto 30 días: vencimiento = fecha de emisión + este plazo. Se aplica al simular una nueva factura; para tu cartera real, calcula la fecha de vencimiento en tu facturas.json con esta misma regla.
Define cuándo una factura pasa a amarillo en el semáforo.

Cargar datos reales

Al publicar en GitHub Pages, sube junto a index.html un archivo facturas.json con un arreglo de objetos { folio, razonSocial, rut, neto, iva, total, emision, vencimiento, pagada }. El dashboard lo detecta automáticamente al cargar y lo usa como fuente de verdad; si no existe, muestra datos de ejemplo. Ese mismo archivo es el que se revisa para el aviso semanal de vencimientos, así que mantenlo actualizado en el repositorio (no basta con "Marcar pagada" en el navegador — eso solo se guarda localmente).
